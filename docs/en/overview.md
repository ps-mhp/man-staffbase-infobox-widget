# Overview

The info box is a colored box used for a brief note: a
bold line, followed by a sentence. The color of the box tells the reader how
urgent the matter is.

## The Five Variants

| Variant | Color | Purpose |
| --- | --- | --- |
| Neutral | Gray | A note without urgency—an addition, a footnote. |
| Information | Blue | News the reader should know. |
| Success | Green | Something has been completed or approved. |
| Warning | Yellow | Something is coming up that affects the reader. |
| Error | Red | Something has failed or is no longer valid. |

Using more than one variant per page dilutes the message. If everything is yellow,
nothing is urgent.

## What the infobox is not

It does not replace a news item or an article. It contains a single sentence, not
a paragraph. If you have more to say, write an article and link to it
in the running text above it.

It is also not a dialog: the close button only removes the box until
the next page load.
