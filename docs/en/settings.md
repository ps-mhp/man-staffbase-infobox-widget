# Settings

| Field | Default | Meaning |
| --- | --- | --- |
| **Variant** | Neutral | The box color: Neutral, Information, Success, Warning, Error. |
| **Heading** | empty | The bold first line. May be left blank. |
| **Text** | empty | The text below. Line breaks are preserved. May be left empty. |
| **Allow closing** | on | Displays the X in the upper-right corner. |

The heading and text must not both be empty—otherwise, the widget
will not display anything.
