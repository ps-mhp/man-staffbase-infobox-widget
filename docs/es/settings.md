# Configuración

| Campo | Valor predeterminado | Significado |
| --- | --- | --- |
| **Variante** | Neutral | El color del recuadro: Neutral, Información, Éxito, Advertencia, Error. |
| **Título** | vacío | La primera línea en negrita. Puede dejarse en blanco. |
| **Texto** | vacío | El texto que aparece debajo. Se conservan los saltos de línea. Puede dejarse vacío. |
| **Permitir cerrar** | activado | Muestra la cruz en la esquina superior derecha. |

El título y el texto no pueden estar ambos vacíos; de lo contrario, el widget
no mostrará nada.
