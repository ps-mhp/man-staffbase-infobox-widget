# Paramètres

| Champ | Valeur par défaut | Signification |
| --- | --- | --- |
| **Variante** | Neutre | La couleur de l'encadré : Neutre, Information, Succès, Avertissement, Erreur. |
| **Titre** | vide | La première ligne en gras. Peut rester vide. |
| **Texte** | vide | Le texte situé en dessous. Les sauts de ligne sont conservés. Peut rester vide. |
| **Autoriser la fermeture** | activé | Affiche la croix en haut à droite. |

L'en-tête et le texte ne doivent pas être tous deux vides — sinon, le widget
n'affiche rien.
