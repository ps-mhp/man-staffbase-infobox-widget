# Étape par étape

## Créer une infobox

1. Dans l'éditeur, à l'endroit souhaité, insérez **Infobox** à partir de la liste des widgets.
   2. Sélectionnez **Variante** — la couleur de l'encadré.
3. Saisir le **titre** : la première ligne en gras.
4. Saisir le **texte** : la phrase située en dessous.
5. Cochez ou décochez la case **Autoriser la fermeture**.
6. Enregistrer.

## Titre uniquement, texte uniquement

Les deux champs peuvent rester vides — mais pas les deux en même temps. Si les deux
sont vides, le widget n’affiche rien ; dans l’éditeur, il n’y a alors
rien à cet endroit. C’est voulu : une zone colorée vide ne ferait que
semer la confusion chez le lecteur.

## Sauts de ligne

Un saut de ligne dans le champ de texte apparaît également sur la page. Deux lignes dans le champ donnent
deux lignes dans l’encadré. En revanche, plusieurs espaces consécutifs sont
fusionnés en un seul.

L’encadré d’information n’est pas destiné aux paragraphes avec des espaces entre eux — il s’agit d’un
article.

## La croix de fermeture

Si l’option **Autoriser la fermeture** est activée, le lecteur voit une croix en haut à droite. Un
clic dessus fait disparaître l’encadré — jusqu’au prochain chargement de la page. Ensuite,
il réapparaît.

Pour un message obligatoire que tout le monde doit voir, désactivez cette option.
