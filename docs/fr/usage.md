# Étape par étape

## Créer une infobox

1. Dans l'éditeur, à l'endroit souhaité, insérez **Infobox** à partir de la liste des widgets.
   La fenêtre **Modifier l'infobox** s'ouvre automatiquement.
2. Sous **Contenu**, saisissez le **titre** : la première ligne en gras.
3. En dessous, saisissez le **texte** : la phrase située sous le titre.
4. Sous **Mise en page**, choisissez une **variante** — la couleur de l'encadré.
5. Sous **Comportement**, activez ou désactivez **Autoriser la fermeture**.
6. En haut, sélectionnez **Ordinateur de bureau**, sélectionnez **Tablette** ou **Mobile** pour voir l’infobox telle
   qu’elle s’affiche sur la page. Pour revenir au formulaire, cliquez sur **Éditeur**.
7. **Appliquer** (⌘/Ctrl S), puis enregistrez la boîte de dialogue des paramètres.

La fenêtre peut être rouverte à tout moment via le bouton **Modifier l’infobox** dans la
boîte de dialogue des paramètres.

## Titre uniquement, texte uniquement

Les deux champs peuvent rester vides — mais pas les deux en même temps. Si les deux
sont vides, le widget n’affiche rien ; et l’éditeur n’affiche alors
rien à cet endroit. C’est voulu : une zone de couleur vide ne ferait que
semer la confusion chez le lecteur. La fenêtre n’affiche donc pas de boîte vide et indique sous
le champ de texte ce qui manque.

## Sauts de ligne

Un saut de ligne dans le champ de texte apparaît également sur la page. Deux lignes dans le champ donnent
deux lignes dans l’encadré. En revanche, plusieurs espaces consécutifs sont
fusionnés en un seul.

L’encadré d’information n’est pas destiné aux paragraphes avec des espaces — il s’agit d’un
article.

## La croix de fermeture

Si l’option **Autoriser la fermeture** est activée, le lecteur voit une croix en haut à droite. Un
clic dessus fait disparaître l’encadré — jusqu’au prochain chargement de la page. Ensuite,
il réapparaît.

Pour un message obligatoire que tout le monde doit voir, désactivez ce bouton.
