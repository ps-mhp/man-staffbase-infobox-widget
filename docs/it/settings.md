# Impostazioni

| Campo | Impostazione predefinita | Significato |
| --- | --- | --- |
| **Variante** | Neutro | Il colore del riquadro: Neutro, Informazione, Successo, Avviso, Errore. |
| **Titolo** | vuoto | La prima riga in grassetto. Può rimanere vuota. |
| **Testo** | vuoto | Il testo sottostante. Le interruzioni di riga vengono mantenute. Può rimanere vuoto. |
| **Consenti chiusura** | attivo | Mostra la croce in alto a destra. |

L'intestazione e il testo non possono essere entrambi vuoti, altrimenti il widget
non visualizza nulla.
