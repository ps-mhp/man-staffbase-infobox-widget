# Przegląd

Ramka informacyjna to podświetlone kolorem pole przeznaczone na krótką informację: jeden
pogrubiony wiersz, a pod nim jedno zdanie. Kolor tła wskazuje czytelnikowi, jak
pilna jest dana sprawa.

## Sześć wariantów

| Wariant | Kolor | Przeznaczenie |
| --- | --- | --- |
| Neutralny | Szary | Informacja bez charakteru pilnego — uzupełnienie, przypis. |
| Informacja | Niebieski | Nowość, o której czytelnik powinien wiedzieć. |
| Wyjaśnienie | Jasnoniebieski MAN | Spokojna, wyjaśniająca informacja — kontekst i ujęcie, bez statusu i nowości. |
| Sukces | Zielony | Coś zostało zakończone lub zatwierdzone. |
| Ostrzeżenie | Żółty | Zbliża się coś, co dotyczy czytelnika. |
| Błąd | Czerwony | Coś nie działa lub straciło ważność. |

Więcej niż jeden wariant na stronie osłabia przekaz. Jeśli wszystko jest żółte,
nic nie jest pilne.

## Czym nie jest infobox

Nie zastępuje ona wiadomości ani wpisu. Zawiera jedno zdanie, a nie
cały akapit. Kto ma więcej do powiedzenia, pisze wpis i umieszcza do niego link
w tekście powyżej.

Nie jest to również okno dialogowe: krzyżyk zamykający usuwa ramkę tylko do momentu
kolejnego wywołania strony.
