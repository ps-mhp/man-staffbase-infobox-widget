# Ustawienia

| Pole | Wartość domyślna | Znaczenie |
| --- | --- | --- |
| **Wariant** | Neutralny | Kolor ramki: neutralny, informacyjny, sukces, ostrzeżenie, błąd. |
| **Nagłówek** | pusty | Pierwszy wiersz pogrubiony. Może pozostać pusty. |
| **Tekst** | pusty | Tekst poniżej. Zmiany wierszy pozostają zachowane. Może pozostać pusty. |
| **Zezwól na zamknięcie** | włączone | Wyświetla krzyżyk w prawym górnym rogu. |

Nagłówek i tekst nie mogą być jednocześnie puste — w przeciwnym razie widżet
nie wyświetli niczego.
