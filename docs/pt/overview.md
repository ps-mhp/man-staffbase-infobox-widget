# Visão geral

A caixa informativa é uma caixa com fundo colorido destinada a uma breve nota: uma
linha em negrito, seguida de uma frase. A cor da área indica ao leitor o grau de
urgência do assunto.

## As seis variantes

| Variante | Cor | Para que serve |
| --- | --- | --- |
| Neutra | Cinzento | Uma nota sem urgência — um complemento, uma nota de rodapé. |
| Informação | Azul | Uma novidade que o leitor deve conhecer. |
| Explicação | Azul-claro MAN | Uma nota tranquila e explicativa — contexto e contextualização, sem indicar estado nem novidade. |
| Sucesso | Verde | Algo foi concluído ou aprovado. |
| Aviso | Amarelo | Há algo iminente que diz respeito ao leitor. |
| Erro | Vermelho | Algo falhou ou deixou de ser válido. |

Mais do que uma variante por página enfraquece a mensagem. Se tudo estiver a amarelo,
nada é urgente.

## O que a caixa informativa não é

Não substitui nenhuma notícia nem nenhum artigo. Contém uma frase, não
um parágrafo. Quem tiver mais a dizer, escreve um artigo e coloca um link para ele
no texto contínuo acima.

Também não é um diálogo: a cruz de fecho apenas remove a caixa até à
próxima visualização da página.
