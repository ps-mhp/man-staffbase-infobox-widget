# Definições

| Campo | Valor predefinido | Significado |
| --- | --- | --- |
| **Variante** | Neutra | A cor da caixa: Neutra, Informação, Sucesso, Aviso, Erro. |
| **Título** | vazio | A primeira linha em negrito. Pode ficar em branco. |
| **Texto** | vazio | O texto abaixo. As quebras de linha são mantidas. Pode ficar vazio. |
| **Permitir fechar** | ativado | Mostra a cruz no canto superior direito. |

O título e o texto não podem ficar ambos em branco — caso contrário, o widget
não exibe nada.
