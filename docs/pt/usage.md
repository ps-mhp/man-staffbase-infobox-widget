# Passo a passo

## Criar uma caixa de informação

1. No editor, no local pretendido, insira **Caixa de informação** a partir da lista de widgets.
   2. Selecione **Variante** — a cor da caixa.
3. Introduza o **Título**: a primeira linha em negrito.
4. Introduza o **Texto**: a frase abaixo.
5. Assinale ou desmarque a opção **Permitir fechar**.
6. Guarde.

## Apenas título, apenas texto

Ambos os campos podem ficar em branco — mas não os dois ao mesmo tempo. Se ambos
estiverem em branco, o widget não exibe nada; no editor, não aparecerá nada
nesse local. Isto é intencional: uma área colorida em branco seria apenas
confusa para o leitor.

## Quebras de linha

Uma quebra de linha no campo de texto aparece também na página. Duas linhas no campo resultam em
duas linhas na caixa. Por outro lado, vários espaços consecutivos são
fundidos num único.

A caixa de informação não se destina a parágrafos com espaços entre si — isso é uma
publicação.

## A cruz de fecho

Se a opção **Permitir fechar** estiver ativada, o leitor vê uma cruz no canto superior direito. Um
clique nessa cruz faz com que a caixa desapareça — até à próxima visualização da página. Depois disso,
ela volta a aparecer.

Para uma mensagem obrigatória que todos tenham de ver, desative esta opção.
