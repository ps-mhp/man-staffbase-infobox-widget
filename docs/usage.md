# Schritt für Schritt

## Eine Infobox anlegen

1. Im Editor an der gewünschten Stelle **Infobox** aus der Widget-Liste
   einfügen.
2. **Variante** wählen — die Farbe des Kastens.
3. **Überschrift** eintragen: die fette erste Zeile.
4. **Text** eintragen: der Satz darunter.
5. **Schließen erlauben** anhaken oder abwählen.
6. Speichern.

## Nur Überschrift, nur Text

Beide Felder dürfen leer bleiben — aber nicht beide gleichzeitig. Sind beide
leer, gibt das Widget nichts aus; im Editor steht dann an dieser Stelle
nichts. Das ist Absicht: eine leere Farbfläche wäre für den Leser nur
verwirrend.

## Zeilenumbrüche

Ein Umbruch im Textfeld steht auch auf der Seite. Zwei Zeilen im Feld ergeben
zwei Zeilen im Kasten. Mehrere Leerzeichen hintereinander fallen dagegen zu
einem zusammen.

Für Absätze mit Zwischenraum ist die Infobox nicht gedacht — das ist ein
Beitrag.

## Das Schließen-Kreuz

Steht **Schließen erlauben** an, sieht der Leser rechts oben ein Kreuz. Ein
Klick darauf nimmt den Kasten weg — bis zum nächsten Seitenaufruf. Danach
steht er wieder da.

Für eine Pflichtmitteilung, die jeder sehen muss, die Einstellung abwählen.
